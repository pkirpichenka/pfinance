# 06. Ключевые решения продукта

Этот файл кратко фиксирует решения, принятые в ходе развития приложения.

## Деньги бизнеса

- Реальные остатки хранятся на банковских счетах и общей кассе.
- Аналитика точки не должна копировать полный остаток общего банковского счёта.
- Наличные трёх студий аккумулируются в одной общей кассе, но доступны в разбивке по точкам.

## Личные деньги

- Главная сумма личных денег включает только личные счета.
- Чистый личный капитал показывается внутри карточки личных денег и считается как личные счета + мне должны − я должен.
- Деньги бизнеса в чистый личный капитал не включаются.

## Долги

- Старый долг можно внести без движения по счёту как начальную дебиторскую/кредиторскую задолженность.
- Долг не прибавляется к банковскому счёту, пока деньги реально не возвращены.
- Долги поддерживают разные валюты и частичные погашения.

## Личная оплата бизнеса

- Расход распределяется по выбранным точкам.
- Личный счёт уменьшается.
- Банковские счета и касса бизнеса в момент оплаты не меняются.
- При необходимости создаётся требование к возмещению от ИП/ООО.

## Сверка

- Пользователь вводит фактический остаток, а приложение создаёт разницу.
- Техническая корректировка не влияет на прибыль.
- Для общей кассы разница распределяется по студиям.

## Интерфейс

- Быстрый компактный ввод должен сохранять реальную сложную логику всех типов операций.
- На мобильном нижняя навигация должна быть стабильной и не перекрывать контент.
- В desktop-блоке счетов карточки не должны обрезаться; на mobile допустима карусель.
- Формат BYN используется для сумм.
- Favicon встроен в HTML.
