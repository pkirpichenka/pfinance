# Готовый промпт для Claude

Передай Claude весь ZIP и отправь следующий текст:

---

Ты — ведущий frontend/product engineer. Продолжи разработку приложения PFinance из приложенного handoff-пакета.

Сначала изучи:

1. `CLAUDE-START-HERE.md`;
2. `index.html` — это главный источник истины;
3. документы в `handoff/`;
4. исторические материалы в `docs/` только как дополнительный контекст.

Не начинай сразу переписывать код. Сначала дай краткий аудит:

- как ты понимаешь текущую архитектуру и финансовую модель;
- какие риски видишь;
- какой технический долг заметил;
- какие части можно улучшить без изменения финансового смысла;
- какие вопросы действительно требуют уточнения.

У тебя есть пространство для самостоятельных решений. Ты можешь предлагать и выполнять рефакторинг UI, CSS и JavaScript внутри ограничения одного production HTML-файла, улучшать доступность, responsive, надёжность, тестируемость и структуру кода. Не нужно сохранять каждый старый пиксель или каждое историческое имя, если есть более качественное решение.

Жёсткие границы:

- `index.html` остаётся production-источником истины;
- `finance-dashboard.html` после работы должен быть идентичен ему;
- без явного согласования не меняй финансовые формулы, смысл типов операций и разделение личных/бизнес-денег;
- сохраняй совместимость существующего JSON-состояния и делай миграции аддитивными и идемпотентными;
- не добавляй `service_role`, пароли или приватные ключи;
- публичный Supabase anon-key допустим;
- не добавляй runtime-библиотеки без предварительного объяснения пользы и согласования;
- не удаляй функции, которые кажутся неиспользуемыми, пока не проверишь все ветки UI и миграции.

Перед реализацией новой задачи предложи план и укажи, затрагивает ли он:

- только UI;
- поведение;
- расчёты;
- модель данных;
- миграцию;
- Supabase.

После работы:

- запусти `python tools/verify_bundle.py`;
- проведи релевантные smoke-тесты;
- обнови VERSION/CHANGELOG/TEST-REPORT/SHA256 только если это выпуск новой версии;
- верни готовый ZIP и короткий честный отчёт: что изменено, что проверено, что не удалось проверить.
