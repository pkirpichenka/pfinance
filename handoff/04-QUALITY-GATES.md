# 04. Проверки и критерии качества

## Перед изменениями

1. Прочитать `index.html` целиком или как минимум затрагиваемые функции и связанные расчёты.
2. Определить, является изменение только UI, изменением поведения или изменением модели.
3. Для модели описать миграцию и обратную совместимость до написания кода.
4. Сделать резервную копию исходного `index.html`.

## После изменений

### Обязательные автоматические проверки

```bash
python tools/verify_bundle.py
```

Скрипт проверяет:

- идентичность двух HTML-файлов;
- синтаксис каждого встроенного JavaScript-блока;
- отсутствие `service_role` и похожих секретов;
- отсутствие неожиданных внешних JS-зависимостей;
- согласованность SHA-256.

### Функциональный smoke test

- Авторизация и восстановление сессии после обновления страницы.
- Создание личного дохода/расхода.
- Доход/расход бизнеса по банковскому и наличному каналу.
- Перевод между личными счетами.
- Перевод между счетами одного юрлица.
- Перемещение между ИП и ООО.
- Инкассация.
- Личная оплата за бизнес с несколькими точками и возмещением.
- Долг в одной валюте с движением денег по счёту другой валюты.
- Частичное погашение долга.
- Сверка банковского счёта и общей кассы.
- Undo составной операции.
- Сброс «Начать с чистого листа» обнуляет opening и limit, не разрушая структуру при выбранном сохранении.

### Финансовые проверки

- Переводы не меняют доходы/расходы.
- Корректировки не меняют прибыль.
- Общая касса равна сумме наличных каналов студий (`reconcile()`).
- Общий банковский счёт ООО не задваивается.
- Чистый личный капитал не включает деньги бизнеса.
- Частичный возврат долга уменьшает долг и увеличивает выбранный счёт без двойного дохода.

### UI

Проверить минимум:

- Desktop шириной 1366–1920 px.
- Mobile шириной 360–430 px.
- Светлую и тёмную тему.
- Нижнюю мобильную навигацию и safe-area.
- Отсутствие горизонтального переполнения страницы.
- Полную видимость последней карточки карусели/сетки.
- Кликабельность периода и кнопки «Внести операцию».
- Favicon после очистки кэша.

- Пересчитать `SHA256SUMS.txt`.
