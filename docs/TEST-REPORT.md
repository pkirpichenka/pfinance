# Отчёт проверки PFinance 4.5.1

Дата: 27 июля 2026 года.

## Объём hotfix

Точечно исправлены три дефекта экрана «Обзор», зафиксированные в приложенном видео и снимке экрана:

1. расширение основного контейнера за пределы мобильного viewport;
2. дублирующая кнопка «Внести» в мобильной верхней шапке;
3. нестабильный выбор периода на десктопе.

Расчётные функции, типы операций, модель хранения и остальные экраны не изменялись.

## Адаптивность обзора

- В CSS Grid правая колонка заменена на `minmax(0,1fr)`.
- Для `.app` и `.main` добавлен безопасный `min-width:0`.
- В мобильном медиазапросе `.main` ограничен шириной viewport и защищён от горизонтального переполнения.
- При viewport 390 px проверено:
  - ширина `documentElement.scrollWidth` — 390 px;
  - ширина `.main` — 390 px;
  - все четыре кнопки периода находятся внутри viewport;
  - карточки обзора больше не растягивают страницу до десктопной ширины.

## Переключатель периода

- Добавлен отдельный контейнер `.overview-period`.
- На мобильном период доступен в компактной горизонтальной строке.
- Кнопкам добавлены `type="button"` и актуальное `aria-pressed`.
- Обработчик принимает только значения `month`, `quarter`, `year`, `all`.
- На desktop viewport 1600×900 и mobile viewport 390×844 проверён переход с «Месяц» на «Год».
- После выбора «Год»:
  - активной становится кнопка `data-p="year"`;
  - подписи меняются на «ДОХОД / ГОД», «РАСХОДЫ / ГОД», «ВЫВЕДЕНО / ГОД» и другие соответствующие значения.

## Мобильная шапка

- Проверено отсутствие `.mobile-top .top-add`.
- Переключатель темы в шапке сохранён.
- Центральная кнопка «Внести» в нижней навигации сохранена.

## Регрессия и сборка

- `index.html` и `finance-dashboard.html` идентичны.
- Все встроенные JavaScript-блоки проходят `node --check`.
- Публичный anon-ключ Supabase сохранён.
- Строка `service_role` отсутствует.
- Единственная внешняя JavaScript-зависимость — `@supabase/supabase-js@2` по ESM.
- Версия модели состояния остаётся 6.
- SQL-миграция не требуется.
- `SHA256SUMS.txt` пересчитан после финальной сборки.
