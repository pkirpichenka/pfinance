# PFinance 4.7.0 — стартовая точка для Claude

Это рабочий handoff-пакет для продолжения разработки PFinance.

## Что читать сначала

1. `index.html` — единственный источник истины по текущему поведению приложения.
2. `handoff/01-PRODUCT-CONTEXT.md` — зачем существует приложение и как устроен бизнес пользователя.
3. `handoff/02-CURRENT-ARCHITECTURE.md` — актуальная архитектура и карта кода.
4. `handoff/03-DATA-MODEL-AND-INVARIANTS.md` — финансовые правила, которые нельзя случайно сломать.
5. `handoff/04-QUALITY-GATES.md` — как проверять изменения.
6. `handoff/05-OPEN-DESIGN-SPACE.md` — где есть свобода для решений и рефакторинга.
7. `handoff/CLAUDE-PROMPT.md` — готовый мягкий промпт для нового чата.

## Источник истины

- `index.html` — production-файл.
- `finance-dashboard.html` — идентичная копия; после изменений файлы должны совпадать побайтно.
- `VERSION.txt` — текущая версия: 4.7.0.

Документы в папке `docs/` содержат исторический контекст и старые ТЗ. Они полезны, но местами устарели. При конфликте приоритет такой:

1. текущий `index.html`;
2. документы в `handoff/`;
3. документы в `docs/`.

## Режим работы

Claude может не только выполнять точечные правки, но и:

- предлагать более удачную архитектуру внутри ограничения «один HTML-файл»;
- реорганизовывать CSS и JavaScript внутри файла;
- улучшать доступность, производительность, UX и тестируемость;
- находить технический долг и предлагать план исправления;
- предлагать аддитивные изменения модели данных с безопасной миграцией.

Однако финансовые формулы, смысл типов операций, разделение личных и бизнес-денег и совместимость существующего JSON-состояния нельзя менять без явного согласования с пользователем.

## Быстрая проверка комплекта

```bash
python tools/verify_bundle.py
```

Скрипт проверит идентичность HTML-файлов, синтаксис встроенных скриптов, отсутствие `service_role`, разрешённые внешние JS-зависимости и внутренние SHA-256.
